# Output Item Label (report)

The **Output Item Label** report generates printable labels for items posted through output on a production order. It pulls the item number, description, and base unit of measure, and encodes the item's tracking number (serial, lot, or package number) as both a linear barcode and a QR code on the label.

You can filter the report by **Order No.** and **Item No.** to limit the labels to a specific production order or item, and you can select the **Item Tracking Type** on the request page to choose which tracking number (serial, lot, or package number) is printed as the barcode and QR code on the label.

## Use cases

[!INCLUDE [report-99000769-scenario](../includes/report-99000769-scenario-include.md)]

Production and shop floor operators can use the report to:

* Print labels immediately after posting output for a production order to identify finished items on the floor.
* Filter by Order No. to print labels only for the items produced on a specific production order.
* Choose the item tracking type (serial, lot, or package) so the correct number is encoded on the barcode and QR code.,Warehouse and inventory staff can use the report to:

* Attach printed labels to output items so they can be scanned during putaway or transfer to storage.
* Use the QR code on the label to quickly look up lot or serial information during inventory counts.
* Filter by Item No. to reprint labels for a specific item without reprinting the entire output batch.
